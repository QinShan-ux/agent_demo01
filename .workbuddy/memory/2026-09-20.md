# 2026-09-20

## cli.py 接上 RAG 闭环：检索前 3 条 → 组装 prompt → LLM 回答

需求：在 `rag/cli.py` 里取召回结果的前三个切片，按用户给定的模板（[系统指令]/[参考资料]/[用户问题]/[要求]）组装成 prompt。

改动（仅 `rag/cli.py`）：
- 新增模块级常量 `ANSWER_TOP_N = 3` 和 `ANSWER_PROMPT`（模板逐字用用户给的那份）
- 新增 `_build_answer_prompt(question, hits)`：参考资料用**单个 `{chunks}` 占位符 + enumerate 拼 1./2./3.**，而不是 `{chunk_1}/{chunk_2}/{chunk_3}` 三个占位符 —— 渲染结果与模板逐字一致，且召回不足 3 条时不会 KeyError
- 循环末尾接 `ranked` → `collapse_by_parent(ranked, ANSWER_TOP_N)` → `_build_answer_prompt` → `llm.invoke(prompt).content` 打印
- `llm = create_model()` 提到循环外，多 query 改写和最终回答共用一个实例
- 顺手清掉用户留的 `ans = []` 占位和一行注释掉的 multi_query

两个设计判断：
- **必须先 `collapse_by_parent` 再截前 3**：父子块策略下按原始排名直接取 3 条，可能全是同一个父块的子块，组装出重复内容
- `--mode all` 时用 `rerank` 那一路组装（整条链路最强的一路）；vector/hybrid/rerank 各用自己那一路

验证：用桩模块（假 agent / rag.retrieval / rag.vector_store）导入 `rag.cli`，喂真实 `chunks.pkl` 跑 `_build_answer_prompt`，渲染出的 prompt 与模板逐字一致，传 1 条切片也不报错。未端到端跑（本机可用解释器都没装 faiss）。
